# Bookbookbook 1.0.1 Release Notes

## 업데이트 노트

- 출력 용지를 선택하면 중철 순서로 정리된 PDF를 실제 인쇄 용지 위에 자동 배치합니다.
- 출력 용지에 들어갈 수 있는 만큼 소책자 스프레드를 배치해 종이 낭비를 줄입니다.
- 양면 인쇄가 맞도록 앞면은 `1 / 3 / 5`, 뒷면은 `2 / 4 / 6` 순서로 같은 위치에 배치합니다.
- 앞뒤 핀 오차가 한쪽으로 몰리지 않도록 출력 용지 안에서 항상 중앙 정렬합니다.
- 출력 용지 위에 배치된 각 소책자 스프레드마다 재단선을 함께 넣습니다.
- 선택한 출력 용지에 소책자 스프레드가 1개도 들어가지 않으면 판형을 키우라는 경고를 보여줍니다.
- 변환 결과에 중철 인쇄면, 출력 용지 장수, 한 장당 배치 개수를 함께 표시합니다.
- 왼쪽 소개 본문 행간을 조금 넓혀 읽기 편하게 조정했습니다.
